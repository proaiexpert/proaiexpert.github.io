This repository contains the production-ready static website for ProAI Expert.

1. **AI Systems**

   - business process simplification

2. **Website Systems**
   - websites under key
   - branding support
   - structured business websites

The website is intentionally built as a **light-first premium static site** suitable for GitHub Pages.

## Deployment (GitHub Pages)

This site is intended to be deployed from the repository root via GitHub Pages.

Typical deployment flow:

1. Push files to the `main` branch
2. Open repository **Settings**
3. Open **Pages**
4. Set source to:
   - **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`

## Notes

- Keep the public repo clean: do not store old ZIP archives in the live site root
- Preserve canonical / hreflang consistency
- Preserve RU/EN page mapping
- Prefer controlled incremental updates over large uncontrolled rewrites
