# Alina Horb Final Assets V1

This directory is the approved screenshot asset package for the future Alina Horb flagship portfolio case.

## Scope

- `masters/` contains eight PNG files extracted byte-for-byte from the approved Google Slides deck.
- `delivery/` contains eight lossless WebP derivatives at the original pixel dimensions.
- `docs/` contains the review index, human-readable manifest, machine-readable checksum manifest, and portrait source note.

Source deck: `ALINA HORB - FINAL SCREENSHOT MASTERS V1` (Google Drive file ID `19tCMVcsFQWIVP77-SKoBMq8ReQwWdsAX5DEyALYjbJU`).

## Handling Rules

The screenshot masters must not be resized, cropped, upscaled, color-adjusted, recomposed, or regenerated. The source captures intentionally use different page zoom levels and image heights.

A separate portrait asset is not included. See [PORTRAIT_SOURCE_NOTE.md](docs/PORTRAIT_SOURCE_NOTE.md) before any future public use.

Start with [REVIEW_INDEX.md](docs/REVIEW_INDEX.md) and verify files against [ASSET_MANIFEST.md](docs/ASSET_MANIFEST.md) or [`asset-manifest.json`](docs/asset-manifest.json).
