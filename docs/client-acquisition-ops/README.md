**Status:** Active operating workspace

**Review cadence:** Weekly operating review

## Purpose

This folder stores the execution layer for ProAI Expert client acquisition: current status, dated decision logs, sales templates, campaign plans, and operating materials.

The canonical strategy remains:

- `docs/CLIENT_ACQUISITION_SOCIAL_AND_SALES_PLAN.md`

Nothing in this folder may override that plan silently. If evidence requires a strategy change, update the canonical plan through a dedicated documentation PR and record the decision here.

## Folder structure

- `CURRENT_STATUS.md` — current execution state and next priorities.
- `logs/YYYY-MM-DD.md` — dated decisions, actions, results, and unresolved questions.
- `sales-kit/` — approved reusable sales materials.
- `campaigns/` — time-bounded outreach and social-selling campaigns.
- `reviews/` — weekly operating reviews and KPI analysis.

## Operating rules

1. Every material decision is dated.
2. Current state is maintained in `CURRENT_STATUS.md`.
3. Historical records are appended to dated logs, not rewritten.
4. Reusable materials receive clear status: Draft, Approved, Deprecated, or Superseded.
5. Do not create another client-acquisition master plan.
6. Every new chat should read, in order:
   1. the canonical plan;
   2. this README;
   3. `CURRENT_STATUS.md`;
   4. the latest dated log;
   5. the relevant approved sales-kit file.
7. Website implementation remains a separate workstream.
