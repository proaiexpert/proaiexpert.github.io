# OFFICIAL TECHNICAL SOURCES

*   **Multilingual and multi-regional sites:** Use different URLs for different language versions and use `hreflang` annotations to map target audiences, avoiding automatic IP-based redirects. (Source: [Google Search Central: Managing multi-regional and multilingual sites](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites))
*   **Hreflang self-reference and reciprocity:** Each language version must list itself as well as all other language versions; if two pages don't both point to each other, the tags will be ignored. (Source: [Google Search Central: Localized Versions](https://developers.google.com/search/docs/specialty/international/localized-versions))
*   **Fully qualified URLs:** Alternate URLs must be fully-qualified, including the transport method (http/https). (Source: [Google Search Central: Localized Versions](https://developers.google.com/search/docs/specialty/international/localized-versions))
*   **X-default:** The `x-default` value is used when no other language/region matches the user's browser setting, acting as a fallback. (Source: [Google Search Central: Localized Versions](https://developers.google.com/search/docs/specialty/international/localized-versions))
*   **Visible language versus HTML lang:** Google uses the visible content of your page to determine its language, not code-level language information such as `lang` attributes. (Source: [Google Search Central: Managing multi-regional and multilingual sites](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites))
*   **Accessibility evaluation limitations:** No automated tool alone can determine if a site meets accessibility standards; knowledgeable human evaluation is required. (Source: [W3C: Evaluating Web Accessibility Overview](https://www.w3.org/WAI/test-evaluate/))
*   **U.S. copyright initial ownership and transfer:** Copyright initially vests in the author, and transfer of ownership requires a written document signed by the owner. (Source: [U.S. Copyright Office: Chapter 2 - Circular 92](https://www.copyright.gov/title17/92chap2.html))
*   **ICANN registrant/registrar relationship:** A domain name registrant is the entity who registers a domain name by entering into a contract with a registrar. (Source: [ICANN: Information for Domain Name Registrants](https://www.icann.org/registrants))
