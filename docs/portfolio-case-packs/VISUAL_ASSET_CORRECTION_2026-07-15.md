**Date:** 2026-07-15

**Status:** Binding correction for all subsequent portfolio work

## Decision

The previously generated desktop/mobile review sheets and synthetic project canvases are rejected as stakeholder-facing portfolio material.

They were layout QA aids only. They are not approved screenshots, not approved visual direction, and must not be used in:

- public portfolio pages;
- case-study pages;
- homepage modules;
- Websites & Branding;
- AI Systems;
- social posts;
- proposals;
- client presentations;
- stakeholder design approval.

## New non-negotiable rule

Every project visual shown publicly must be one of the following:

1. a current screenshot captured from the actual live website;
2. a current screenshot rendered from the exact current production source and production assets;
3. a real source image already used on the live website, when the design specifically calls for an isolated asset rather than a page screenshot.

No synthetic replacement, generated interface, invented site screen, ratio-matched stand-in, or generic canvas may represent a real project.
