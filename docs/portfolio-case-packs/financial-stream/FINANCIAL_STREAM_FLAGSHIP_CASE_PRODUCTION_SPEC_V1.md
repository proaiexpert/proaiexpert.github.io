## 8. Opening motion

### Effect 1 — Evidence Lock

Purpose:

The real homepage screenshot is placed into a verifiable system rather than theatrically revealed.

Rules:

- text and screenshot are visible at first paint;
- no loader;
- no masked LCP delay;
- no scale;
- no blur;
- no parallax.

Start state:

- screenshot `translateX(10–12px)`;
- opacity approximately `0.96`;
- registration mark and source baseline slightly misaligned.

End state:

- screenshot `translateX(0)`;
- opacity `1`;
- screenshot, mark and source baseline align.

Timing:

- desktop: 650–720 ms;
- mobile: 480–520 ms with 6–8 px movement.

Easing:

`cubic-bezier(0.22, 1, 0.36, 1)`

Reduced motion and no JavaScript:

- render final state immediately.

## 14. Motion system

Exactly six effect classes are permitted.

All other headings, paragraphs, lists, captions, links and status labels remain static or use normal browser interaction states.

### Effect 1 — Evidence Lock

Defined in Section 8.

### Effect 2 — Layer Reconciliation

Purpose: align the active layer with the Register.

- trigger: active article enters central reading band;
- movement: maximum 4–6 px;
- duration: 240–300 ms;
- easing: `cubic-bezier(0.22, 1, 0.36, 1)`;
- mobile: static;
- reduced motion: static active marker.

### Effect 3 — Proof Surface Settle

Purpose: place a real screenshot as evidence.

- screenshot is already visible;
- start: `translateY(8–12px)`, opacity approximately `0.96`;
- end: final position, opacity `1`;
- duration: 420–500 ms;
- mobile: 4–6 px, 300–340 ms or static;
- no scale, blur, clip theatre or parallax;
- never animate more than one large raster screenshot at a time.

### Effect 4 — Surface Handoff

Purpose: distinguish analytical dark chapters from documentary light chapters.

- confined boundary band only;
- duration: 360–440 ms;
- no full-background scroll scrub;
- mobile/reduced motion: static hard transition with a short boundary marker.

### Effect 5 — Source Lock

Purpose: show that a value becomes evidence only with period, source and limitation.

- metric is already visible;
- source rule reveals through transform;
- source/date/limitation gain final contrast;
- duration: 320–380 ms;
- numbers remain static.

### Effect 6 — Register Closure

Purpose: resolve the evidence system into the final action.

- short registration segments align into one CTA-leading rule;
- duration: 480–560 ms;
- buttons and copy remain visible throughout;
- reduced motion: render final line immediately.
