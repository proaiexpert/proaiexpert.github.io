## Current publication rule

Use the AVIF as the first `<picture>` source and WebP as the fallback `<img>` source.

Requirements:

- preserve full interface context;
- no crop that removes the selected period, update date, metrics or chart;
- no arrows, badges or altered values;
- include intrinsic width and height;
- use `loading="lazy"` and `decoding="async"`;
- keep the numeric evidence in HTML text as well as in the screenshot;
- use independent EN and RU alt text and captions.
