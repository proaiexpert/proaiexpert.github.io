# Financial Stream LLC — Screenshot Manifest

## Capture gate

Portfolio screenshots must be captured from the current live site after the visible payroll conflicts are removed and the latest deployment is verified. Do not use old ZIP builds or local previews as final portfolio evidence.

Use two asset classes:

- **Portfolio masters:** clean browser-free captures for public design presentation.
- **Evidence captures:** raw screenshots preserving dates, UI context, and status information.
