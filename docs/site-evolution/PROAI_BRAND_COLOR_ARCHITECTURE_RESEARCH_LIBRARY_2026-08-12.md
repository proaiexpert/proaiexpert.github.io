## 2. CORE BRAND COLOR ARCHITECTURE — WORKING DIRECTION

The current strongest system separates color by **function**, not by one traditional brand color.

### A. MATERIAL / STRUCTURAL COLORS

Permanent or near-permanent brand physics:

- Obsidian / near-black
- Graphite
- Gunmetal
- Black chrome
- Smoked graphite
- Pearl / warm pearl / silver

These define the structural identity.

### B. HUMAN / UI MATERIAL COLORS

Warm tactile interface family:

- Champagne
- Warm pearl
- Ivory / off-white

Working warm metallic family:

- Champagne base: `#C7A768`
- Champagne highlight: `#D8BD84`
- Champagne deep / bronze edge: `#9A6F38`

Use for possible:

- CTA material/detail
- focus
- partial active edge
- selected state
- tiny premium UI detail

Do **not** automatically make champagne a global brand fill.

### C. MACHINE / AI / ATMOSPHERIC ENERGY

Cold spectral environmental family:

- Spectral indigo: `#676BFF`
- Deep spectral: `#5B50FF`
- Ice / periwinkle reflection: `#9BA8FF`

Use as possible:

- Cube-local environmental reflection
- semantic activation light
- rare spatial event
- machine/AI energy

Do **not** use by default for buttons, H1, eyebrow, navigation or ordinary card fills.

### D. CONTEXTUAL TINT

A future content-specific color layer for:

- case studies
- articles
- insights
- campaign/editorial pages
- selected page families

A contextual tint may influence imagery, cover, one edge, local light, illustration or section atmosphere without replacing the core brand system.

Contextual tints must not randomly recolor the entire interface.

Neutral Obsidian + owner-approved Cube graphite/gunmetal/black-chrome.

### Human/UI material

Warm Pearl + Champagne.

The metaphor should be felt visually, not explained in copy.

## 10. BLACK-ON-BLACK RULE

Future dark UI should use hierarchy from multiple simultaneous cues:

- surface value
- border luminance
- elevation/shadow
- material response
- content luminance

Do not rely on one black everywhere.

Use a structure like:

`PAGE → SURFACE → PANEL → CARD → NESTED OBJECT`

without forcing a hue change at every level.

## 11. LIGHT / DARK INVERSION RULE

ProAI is currently **dark-first, not dark-only**.

Future brand system should support:

### Dark mode

Obsidian + pearl typography + graphite cards + controlled warm UI + occasional cool machine energy.

### Light inverse

Warm Pearl `#F2EFE8` + ink `#111315` + graphite/black-chrome contrast cards + selected warm metallic detail + spectral color mainly in imagery/illustration/special spatial events.

Possible later uses:

- section boundaries
- proof/case-study surfaces
- selected editorial panels
- detail pages
- article/case covers
- future Logo presentation
- modal/feature surface

Do not make Hero half-white merely to prove inverse capability.

## 14. REFERENCE LESSON LIBRARY

Preserve these principles for future work.

### Resend

- localized color behaving as reflection/light
- mostly neutral components with small chromatic locus
- partial active edges
- multi-hue can work when brand grammar is stable

Do not copy feature-color taxonomy, square-object grammar or exact lower-edge language.

### Black Forest Labs

- dark → light → dark rhythm can remain one identity
- off-white cards can coexist with dark chrome
- very soft tinted light CTA can feel premium

### Runway

- editorial black/white inversion
- small warm metallic/status accent
- content/art can carry richness while UI remains disciplined

### Rive

- black-on-black hierarchy
- raised charcoal surfaces
- very thin borders
- occasional warm detail without recoloring the interface

### Raycast

- strong saturated atmospheric color can remain premium when UI stays restrained
- saturation should be controlled by **location/function**, not banned globally

### Vercel

- monochrome limit case
- precise nested blacks
- hairline borders
- value hierarchy can carry a complete interface without hue

Use as discipline benchmark, not automatic ProAI identity.

## 15. RESEARCH PRINCIPLES TO KEEP

1. Premium does **not** equal monochrome.
2. Restraint does **not** mean absence of invention.
3. Color should be assigned by function.
4. Strong color can be allowed locally if UI remains controlled.
5. Material/light/composition can be more important than one fixed brand hue.
6. The Cube should carry much of the Hero richness.
7. UI color and atmospheric color are separate systems.
8. Dark-first does not mean dark-only.
9. Contextual tint can give cases/articles individual character without fragmenting the brand.
10. Do not restart large benchmark research unless a future problem genuinely lacks evidence.
