## Owner verdict

The current owner-review browser composition is **not approved**.

The problem is no longer missing/broken image assets. The C-shape Core now renders, but it still reads as a **separately cut-out object placed on a black page**, not as a premium integrated cinematic 3D scene.

This is an art-direction / compositing / responsive composition failure, not a rejection of the C-shape concept, the new EN/RU copy architecture, or the semantic journey.

## What is visually wrong

1. **The Core is spatially isolated.** It sits as a freestanding object with insufficient environmental continuity into the page.
2. **Grounding is too weak.** Contact shadow, floor plane, reflected cyan spill and nearby atmosphere do not visually bind the object to the Hero background strongly enough.
3. **The scene has an implicit cut-out / plate boundary.** Even without a literal rectangle, the eye reads the Core as a separate image region rather than one continuous spatial composition.
4. **The Core is too small relative to the H1 on desktop.** The signature visual should be co-dominant, not a secondary illustration floating at the far right.
5. **The rail is too detached from the physical scene.** It currently reads like HTML labels beside an image rather than semantic stages belonging to the visual system.
6. **The signal does not yet create a living spatial journey.** The current image needs controlled overlay motion to feel like a live system rather than a static raster.
7. **Portrait/mobile behavior must not shrink the full scene until it becomes unreadable.** On narrow vertical screens the visual should move below the copy and remain large enough to preserve material detail and spatial authority.

## Direction change — do not keep patching the isolated object

The next pass must stop treating the Core as a transparent object that needs to be made to look grounded.

Instead treat the right side of the Hero as a **single integrated cinematic scene field**.

Preferred implementation architecture:

### Layer 1 — wide integrated scene plate

Use the authoritative visual direction to create / derive a wide scene plate containing:

- the full C-shape Core;
- contact shadow;
- dark floor plane;
- floor reflection;
- cyan reflected spill;
- local atmosphere / light falloff;
- enough surrounding darkness for the scene to dissolve naturally into the page background.

The scene plate must have **no baked header, H1, support text, CTA or semantic labels**.

The scene should fade into the browser background through large soft atmospheric falloff, not an object-shaped alpha cutout.

The goal is for the user to perceive one spatial Hero environment, not `text + inserted image`.

### Layer 2 — sharp Core detail only if genuinely needed

A sharp foreground Core overlay may be retained only if it improves material detail without reintroducing a sticker/cutout contour.

If the wide scene plate is visually strong enough by itself, prefer the simpler single-scene solution.

### Layer 3 — motion overlays

Do not rotate, bob or parallax the physical Core.

Animate only system intelligence / light:

- subtle internal cyan breathing;
- one controlled signal pulse through the C-shape;
- local response in the rail stages as the signal reaches them;
- restrained floor/cyan light response;
- optional minimal CTA edge accent.

The physical object and its floor remain registered and stable.

Not:

- floating 3D card;
