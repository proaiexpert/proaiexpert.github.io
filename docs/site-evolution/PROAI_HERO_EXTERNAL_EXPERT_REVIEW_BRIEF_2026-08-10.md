## Current proposed direction — HYPOTHESIS, NOT A DECISION

We are considering reusing the reliable architecture of the older production Hero but rebuilding its art direction and storytelling completely:

### Hybrid Connected System Core

- Keep the approved/current left-side communication architecture.
- Use one seamless near-black Hero environment.
- Replace the old simplistic cube with a much more premium real-time 3D `System Core`.
- Core material direction: rich graphite / gunmetal, cold steel, smoked glass, restrained cyan internal light, very subtle blue-to-champagne pearlescent reflections, realistic roughness/specular variation.
- Avoid obvious neon, chrome toy, gold luxury, crypto, gaming or Tron aesthetics.
- Convert the four old equal service cards into a sequential journey: `TRUST → INQUIRY → RESPONSE → RESULT`.
- Cards become premium spatial plates: graphite/smoked glass, excellent typography, short explanatory microcopy, subtle depth/material response.
- Use WebGL/Three.js primarily for the 3D Core/material/light/particles.
- Keep typography and process cards as real HTML/DOM for sharpness, accessibility, responsiveness and reliable mobile behavior.
- Orchestrate Core + cards with one controlled motion timeline.
- Motion should explain the system: stage activation, input → processing → handoff → result, not decorative perpetual VFX.
- Neutral static state must already look excellent.
- Reduced-motion state must remain complete and premium.

Possible sequence:

1. TRUST card activates / approaches foreground.
2. A restrained signal enters or affects the Core.
3. INQUIRY activates and the Core responds.
4. RESPONSE activates with a stronger but controlled internal intelligence signal.
5. RESULT resolves the sequence and the system briefly reads as one connected mechanism.
6. Return to a calm idle state.

This is only the current hypothesis. If you can propose a stronger architecture with lower risk or higher premium potential, say so explicitly.
