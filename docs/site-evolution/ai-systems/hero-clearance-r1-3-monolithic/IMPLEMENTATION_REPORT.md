- one near-black faceted structural chassis;

- one narrow local structural clearance seam;

CHASSIS DESIGN

The chassis is built from a subdivided icosahedral base, then transformed into an authored asymmetric compressed industrial volume.

Approximate chassis radii:

`1.54 × 1.27 × 1.34`

The chassis intentionally includes:

- left-side shoulder compression;
- slight crown correction;
- rear taper;
- small non-spherical deformation.

It is not a perfect sphere.

It is not an animated core.

It is not a portal/ring.

It is not a visible backing ball.

Its role is physical seating, mass, continuity and internal shadow.
