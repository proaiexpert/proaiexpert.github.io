## Нативное изменение материалов

После подтверждения независимого файла изменён общий материал исходного компонента Instance; геометрия не заменялась.

Наблюдавшиеся исходные цвета Depth radial gradient включали `000000`, `0AB6BC`, `B2F326`, `FFFFFF`. Выполнены изменения:

- Depth `000000` → `353E49`;
- Depth `0AB6BC` → `566270`;
- Depth `B2F326` → `D5DDE6`;
- яркий стоп Depth `FFFFFF` оставлен без изменений;
- Fresnel `2AEEE9` → `D5DDE6`;
- Lighting `60` оставлен без изменений.

Изменение сразу стало визуально видно на повторяющихся элементах Orb в редакторе и опубликованном Viewer. Зелёный/teal/lime удалён из материалов самого Orb; текст сцены по-прежнему содержит собственный teal-акцент и не редактировался. Orb сохраняет тёмно-графитовый объём и серебряные края, видим на чёрном фоне. Палитра применена **частично**: использованы graphite, gunmetal и pearl silver; Obsidian `#10141B` отдельно не вводился. Это первая ограниченная адаптация, не финальная арт-дирекция.
