## WHITE PARTICLE CAUSE — bounded native diagnostics

| Тест | Единственное изменение | Наблюдение / предел вывода |
|---|---|---|
| 1 Depth | В source Instance stop #D5DDE6 при 83.0986% временно заменён на #353E49 | Яркие элементы полностью не исчезли. Stop восстановлен. Это не доказательство, что весь Orb имел один материал. |
| 2 Fresnel | Временное выключение слоя выбранного source material | Не обеспечило доказанного полного устранения bright particles. Восстановлен; влияние ограничено различиями material scope. |
| 3 Lighting | Временное включение исходного Lighting | RESPONSE всё ещё показывает светлые элементы. Восстановлен. |
| 4 States / instances | Осмотр Group/Sphere Base и State, Clone 249 | Изменяются исходные transform/scale; material параметры source и instance различаются. В Sphere State UI Depth World Origin показывает 314.11/-5/5.69 против Base 0.09/-0.59/0.03; stops те же. |
| 5 Projection | Временный World → Local на исходном Sphere | UI автоматически переводит origin в 55.69/3.17/0.02; flash ещё наблюдался. Возвращён World и исходный origin. Поэтому только этот toggle не объявляется решением. |

Наблюдаемый механизм: исходный World Depth с яркими stops взаимодействует с State-трансформациями; единичные правки source не равны единым параметрам всех Clones. Различие displayed Origin само по себе не доказывает отдельный записанный material override: в ограниченной проверке он не отделён от преобразования координат UI при State transform. **Единственная исключительная причина/доля Fresnel против Depth не изолирована.** Это уточняет предварительное наблюдение в комментариях: нельзя без дополнительного доказательства назвать конкретный state override единственным виновником.

Практически подтверждённое снижение: назначение согласованного native Material Asset, Local Depth shading каждого элемента и отсутствие Fresnel в A/B сохраняют затенение частиц в RESPONSE. Не отключались pointer response, Distance или State Change.

## PROVISIONAL SELECTION

Выбран A: более тёмная масса, сдержанное серебро, читаемое локальное затенение, меньше риска превратить весь Orb в светлую сборку. B сильнее отделяет illuminated surfaces, но ближе к избыточно светлому объекту. Оба сохраняют исходную сферическую композицию и работают на тех же motion states. Это provisional selection, не Owner approval.

A назначен группе Clones; затем тот же asset выбран у исходного Sphere при выбранном существующем State. В UI Sphere, Group и Clones в Base/State отображают A. Нативные ссылки на материалы изменены, object hierarchy и event graph не менялись.

## DESKTOP QA / editor limitations

Editor Preview и опубликованный Public Viewer визуально различают A/B и сохраняют reaction/return.

В editor Preview зарегистрированы:
- lerpMaterial: unexpected material layer for colors, TypeError: o[e] is not iterable — предупреждения повторились и в свежем Preview;
- WebGPU Invalid TextureView / CommandBuffer при смене viewport в fullscreen editor Preview; screenshot capture завис, reload восстановил editor;
- ограниченная проверка совместимости layer2 (Color → Depth с постоянным Deep Steel) не убрала lerpMaterial и была полностью возвращена к описанному A.

Не заявляется, что editor-интерполяция исправлена. В свежем опубликованном Public Viewer desktop и mobile во время фактически выполненных тестов error/warn entries не наблюдались. Это ограниченный результат этих сессий, не гарантия отсутствия ошибок во всех движках.
