## Cube material reference findings

Изучен assets/js/proai-hero-cube-r1/source-materials-r1.js. Graphite #242A31: metalness .84 / roughness .295; gunmetal #2B323A: .86/.265; black chrome #181D23: .92/.225. Cube использует PMREM из четырёх reflection cards, hemisphere .52 и три area lights key5.2/fill4/rim4.6, ACES exposure1. Эти Three.js механизмы не объявлены доступными в Spline.

## Native Spline options и фактические изменения

Native меню предлагает Point / Directional / Spot, Area Light в нём не обнаружен. Reflection layer оказался SSR с Surface Shape / Hi-Z, а не PMREM environment. Проверены Physical Lighting, Depth enable/order, native Matcap.

Исходный Depth100 над Lighting100 визуально подавлял Physical. В отдельном asset PROAI R2.7 — STUDIO TITANIUM стек теперь:

1. Matcap45 Normal, native matcap_reflection_3.png, rotation0, Color.
2. Physical Lighting100 Normal: roughness .48, metalness .86, reflectivity .35, clearcoat .10, coat roughness .10, black emissive power1, IOR1.50, occlusionOn, mapsNone.
3. Исходный Depth сохранён, но выключен. Все stop/Local/Vector параметры в JSON.
4. Color100 Normal #242A31.

Fresnel отсутствует. Это native hybrid с camera-normal Matcap, а не физически точная копия Cube studio reflections. Вращение меняет рисунок бликов на поверхности; отделить в итоговом hybrid вклад прямого света от Matcap по одному кадру нельзя.

Добавлены два Directional Light: key #D5DDE6 intensity1.2 position0/0/500 rotation−35/0/0; fill #98A7B6 intensity.55 position−400/180/400 rotation20/−40/0. ShadowsNo. Ambient #D3D3D3 .75 не менялся. Геометрических reflection cards и новых сфер нет.

## Контролируемые тесты

Lighting поднят выше Depth; ambient-only Physical оказался очень тёмным. Key3 дал яркие точки и уменьшен до1.2. Roughness .32→.48 смягчил блики. Metalness .72→.86. Depth выключен обратимо. Studio dark/LED текстуры отклонены за полосы/кольца; matcap_1_11 при55 отклонён за слишком тёмные активные элементы; reflection_2 при55 — за серый пластиковый вид. Выбран reflection_3 при45. Не создавалась индивидуальная случайная раскраска250 элементов.

Доказательства отвергнутого блика key3 и выбранного shader записаны. Исходные A/B не перезаписаны. Не все промежуточные однофакторные тесты имеют отдельный кадр; не заявляется количественное исследование BRDF.

## Metallic reflection results

По сравнению с R2.6 появился тёмный glossy body и серебристая кривизна вместо доминирующего painted Depth. Уровень premium metal остаётся частичным: рисунок бликов местами однотипен, а мелкие RESPONSE particles слишком темны. Массового white flood в финальных записях не наблюдалось. Нет cyan/teal/lime, bloom либо независимых случайных вспышек. Полный Cube-like quality PASS не присвоен.

## Reactive motion parity / touch

Геометрия, transforms, Distance, Follow, State Change и native states не менялись. 250 named Clone groups — сохранённая проверенная база R2.3/R2.6, не новый полный recount R2.7. Shared material назначен Clones и source Instance; Group Base / Sphere State показывали тот же asset.

Desktop1440×900: REST целая сфера; PRESS/DRAG дают выраженное пространственное раскрытие; RELEASE и pointer-away возвращают силуэт. При максимальном раскрытии видимость мелких частиц недостаточна для полного визуального PASS.

Mobile390×844: REST bbox44/269/343/572, ширина299px =76.67%, без обрезания. R2.6 было306px/78.46%; небольшое отличие связано с текущей ориентацией/яркостным порогом, камера не уменьшалась. Personal Camera180%, Responsive, Auto ZoomYes сохранены.

TouchEnd возвращает основной силуэт, иногда остаётся активная маленькая частица. После touchEnd DOM сохранял HTML/BODY/CANVAS:hover; Follow reset исходно Hover Out. После перемещения указателя за viewport видна связная сфера. Это свидетельствует в пользу mismatch touchEnd/hover reset, но не доказывает конкретную внутреннюю причину. События не переписаны, исправление touch recovery не заявлено.

Fullscreen Viewer scrollHeight=clientHeight844: скролл родительского Hero не проверяется этой страницей. Физический iPhone не тестировался. Mobile emulation не означает iPhone PASS.

## Публикация и renderer

Перед изменениями наблюдался WebGPU DXGI_ERROR_DEVICE_HUNG. Через официальный selector выбран WebGL2Only. Публикация сначала задержалась с Image compression skipped for image matcap_reflection_3 / Worker pool worker failed. После подтверждения server save и одного reload/retry завершилась; UI показал The URL content has been updated. Свежий public Viewer подтвердил новый материал; desktop/mobile записи сделаны именно в нём.

Затем отдельно нажат Update Viewer; busy состояние вернулось к доступной кнопке. Официальный runtime URL отображён. Прямой embed scene.splinecode отдельно не проверен.

WebGL warning: document uses PBR material maps ... classic WebGL pipeline does not render. У выбранного материала поля mapsNone, но document-level warning сохраняется. Не заявляется полная PBR-map или WebGPU совместимость. Старое lerpMaterial предупреждение редактора не исправлено; в тестируемом public Viewer оно не наблюдалось.

## R2.7 targeted continuation — 2026-10-17 Owner / 2026-10-18 UTC

**Текущее состояние: PARTIAL.** Этот раздел обновляет начальный R2.7 выше. Исходный опубликованный Matcap45 Normal зафиксирован commit c5a99db2eb4e0fc5b132c71fa11da76d2f2e6b12 и сохранён в JSON initial_r27_selected_material.

### Реальная коррекция

Один параметр: Matcap blend **Normal → Screen**, opacity45 сохранена. Остальные material/light/camera/geometry/event/state параметры не менялись. Native Preview и свежий Public Viewer показывают более заметные серебристые блики при тёмном корпусе. Это qualitative comparison с продолжающейся ротацией, не измерение BRDF или pixel-matched pose.

Screen не решил весь контраст: на минимальном размере активные beads остаются очень тёмными. Поэтому signature-quality PASS не присвоен. Нет новой геометрии, индивидуальной250-объектной раскраски, glow либо runtime setters.

### Motion и touch recovery

Повторно просмотрен исходный Cursor Follow: Aligned with camera, XY, damping1, offset0, Hover Out, resetSpeed5. В reset доступны только Hover Out / No Reset. В event selector видны Mouse Up/Down/Press/Hover, но отдельного Touch End нет. Selector закрыт без изменения события. Добавление Mouse Up с новым State/глобальным reset не выполнялось без доказательства совместимости с Follow.

Новая mobile запись длится7.678s: после touchEnd основной и конечный силуэт возвращается в плотную сферу, без введённого hover-out. DOM всё ещё содержит CANVAS:hover. Это уточняет старый короткий тест: остаточный отклик не оказался постоянно воспроизводимым при более длительном settling. Нельзя объявить все touch-reset проблемы исправленными; engine cause остаётся не изолирован. События не менялись.

### Итоговая QA

- Desktop1440×900:82 реальных кадров,4.688s, REST/PRESS/DRAG/RELEASE/RETURN. Сфера восстанавливается, массового белого пересвета нет. Минимальные частицы плохо читаются.
- Mobile390×844:182 реальных кадра,7.678s; сфера полностью видна, REST bbox46/272/342/566 =296px /75.90% ширины. Camera180%, Responsive, AutoZoomYes не менялись; ориентация и порог яркости меняют bbox.
- Физический iPhone и scroll родительского Hero не проверены.
- Эмуляция viewport/touch сброшена.
- В публичном Viewer остаётся warning о PBR material maps classic WebGL; errors не наблюдались в этой проверке. WebGPU compatibility не заявлена.
- Материальная иерархия подтверждена UI: Matcap45 Screen / Lighting100 Normal / Depth disabled100 Normal / Color#242A31.
- Public URL обновлён один раз, кнопка вернулась enabled; свежий Viewer визуально подтвердил Screen-кандидат. Update Viewer выполнен один раз, busy→enabled. Runtime URL неизменен; прямой embed отдельно не проверен.
