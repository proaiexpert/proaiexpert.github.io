# 3. FROZEN SEMANTIC ARCHITECTURE

The system is:

`TRUST → INQUIRY → RESPONSE → RESULT`

Russian:

`ДОВЕРИЕ → ОБРАЩЕНИЕ → ОТВЕТ → РЕЗУЛЬТАТ`

These four stages are **not** four cards, four services or four colored categories.

They are four connected moments inside **one continuous business system**.

Meaning:

- **TRUST** — website, brand, visual presentation, first impression.
- **INQUIRY** — forms, calls, messages, CRM entry points.
- **RESPONSE** — AI, automation, routing, follow-up.
- **RESULT** — defined next business action / measurable outcome.

`RESULT` is not a guaranteed sale/revenue claim. It means a defined next business outcome.

- light behavior;
- exact geometry;
- timing;
- typography hierarchy;
- negative space.

Not from decorative quantity.

# 8. MOTION SYSTEM — HARD LOCK

R1.3 is not a static section.

It is a living optical mechanism.

The main semantic choreography is:

**TRUST becomes active**  
→ physical handoff through rail  
→ TRUST settles / retains short material memory  
→ **INQUIRY becomes active**  
→ handoff  
→ INQUIRY settles  
→ **RESPONSE becomes active**  
→ handoff  
→ RESPONSE settles  
→ **RESULT becomes active**  
→ final balanced state

Desktop/laptop sequence duration is approximately **3.1 seconds**.

Stage-to-stage activation spacing is approximately **520 ms**.

There are explicit visual states:

- future;
- arriving;
- active;
- departing;
- settled;
- balanced.

Only one stage should be primary at a time during the sequence.

# 11. TRANSFER MEMORY / AFTERGLOW — HARD LOCK

When focus leaves the current stage, the previous stage does not instantly collapse.

It retains approximately **360 ms** of weak reflected material memory:

- junction edge;
- rail territory;
- title luminance;
- incision definition.

Then it settles.

This is not a glow trail.

There must be no persistent luminous path.

# 13. MOBILE BEHAVIOR — HARD LOCK

Mobile is NOT four stages squeezed into one viewport.

Do not force the full four-stage system into `100svh`.

Primary portrait sizes:

- `390×844`
- `430×932`

Phone landscape:

- `844×390`
- `932×430`

Mobile uses:

**VERTICAL MACHINED RAIL + NATURAL SCROLL**

No carousel.

No snap.

No horizontal scrolling.

No pinned multi-screen storytelling.

No scroll-jacking.

As the user naturally scrolls, the stage inside the active reading zone becomes active.

The system must work in both scroll directions.

Example:

ДОВЕРИЕ active  
→ scroll down  
→ material handoff travels down vertical rail  
→ ОБРАЩЕНИЕ active  
→ then ОТВЕТ  
→ then РЕЗУЛЬТАТ

Scroll upward should restore previous stage focus naturally.

The active stage is clearly brighter / Pearl, while previous stages settle and future stages remain readable.
