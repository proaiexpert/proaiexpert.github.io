## R1.3 signature optical system

- The R1.2 `future → active → settled` stage model, desktop sequence and reversible mobile reading-zone focus remain intact.
- One **Light Carriage** now coordinates rail focus, transfer joint response, local environment and active-stage illumination as one optical condition.
- The desktop story retains the ~3.1 second tempo with 520ms stage-to-stage activation spacing.
- Every activation receives a one-shot ~350ms Silver/Pearl typographic specular catch using an `aria-hidden` decorative overlay; semantic H3 text remains unchanged.
- Departing stages retain approximately **360ms** of material memory before settling, without a glow trail or persistent luminous line.
- Desktop ambient life remains secondary at **8–13 seconds** and below the active-stage amplitude.
- Mobile remains natural-scroll controlled; the same optical carriage travels with the vertical rail focus and no offscreen stage autoplay is introduced.
- Mobile random ambient motion remains disabled; scroll focus is the primary living behavior.

## Review-only Header parity

- Production Header CSS/JS are not modified.
