# 1. PURPOSE

This document compares three complete visual directions for the accepted Homepage V2 architecture.

The task is not to choose colors in isolation. Each concept must prove that the same ten-block commercial journey can feel:

- premium enough for an ambitious international AI and automation studio;
- credible to U.S. service-business owners;
- technically capable without appearing experimental or unreliable;
- visually distinctive without becoming a generic SaaS template;
- readable in EN and RU;
- maintainable in a later production implementation.

The accepted content order, proof hierarchy, CTA model, project statuses, Header boundary, Footer boundary, and responsive requirements remain locked.

# 3. CONCEPT A — PRECISION GRID

## Positioning

**Technical authority with disciplined premium restraint.**

This direction evolves the current dark/cyan ProAI identity into a more controlled and less theatrical system. It keeps the recognizable technical signal while replacing excessive sci-fi effects with hierarchy, evidence, and precision.

## Visual system

```text
Background:       #06080B
Primary surface:  #0E1319
Raised surface:   #131B23
Primary text:     #F5F8FB
Muted text:       #91A2B3
Primary accent:   #66E3FF
Secondary accent: #0A8DFF
```

## Defining characteristics

- dark graphite field;
- restrained cyan signal rather than constant glow;
- fine technical grid used as atmosphere, not decoration;
- compact section numbering and system labels;
- strong white typography;
- moderate corner radius;
- screenshot and proof areas remain visually dominant;
- precise lines and connected-step geometry;
- visual language suitable for later subtle motion.

## Commercial effect

The concept communicates:

- advanced technical capability;
- control and reliability;
- strong AI/automation identity;
- premium execution without looking like a gaming interface.

## Main risk

If production adds too much glow, animation, glass, or 3D, the concept could regress into the current site's more theatrical sci-fi language. The production rule would need to be: **signal, not spectacle**.

# 4. CONCEPT B — EXECUTIVE SIGNAL

## Positioning

**Consulting-grade editorial clarity with a premium technology accent.**

This direction uses a warm light field, black editorial typography, and a controlled blue signal. It deliberately moves away from the visual conventions of dark AI websites.

## Visual system

```text
Background:       #F3F0E9
Primary surface:  #FBFAF7
Raised surface:   #E7E1D8
Primary text:     #171717
Muted text:       #6A665F
Primary accent:   #185ADB
Deep accent:      #0C285E
Supporting warm:  #B08954
```

## Defining characteristics

- warm pearl background;
- editorial rather than interface-led composition;
- near-square cards and rules;
- strong typographic contrast;
- blue used as an intentional signal;
- evidence treated like a premium case-study publication;
- low visual noise;
- strongest print/editorial brand potential of the three.

## Commercial effect

The concept communicates:

- executive credibility;
- strategic maturity;
- clarity and trust;
- premium advisory positioning.

## Main risk

It may under-communicate AI systems and automation capability unless technical details, system diagrams, and motion are introduced with care. It can also become visually similar to high-end consulting firms if the ProAI-specific system language is not protected.

- `concepts/concept-b-executive-signal-1440.svg`
- `concepts/concept-b-executive-signal-390.svg`

# 5. CONCEPT C — LUMINOUS SYSTEMS

## Positioning

**Immersive AI presence with layered system energy.**

This direction uses deep navy, mint signal, violet depth, rounded fields, and connected luminous paths. It is the most future-facing and visually expressive candidate.

## Visual system

```text
Background:       #07101E
Primary surface:  #0D1A2D
Raised surface:   #132946
Primary text:     #F4F8FF
Muted text:       #9DB0CB
Primary accent:   #79F2D0
Secondary accent: #7D6CFF
```

## Defining characteristics

- deep navy rather than black;
- mint-to-violet system paths;
- larger radius and more dimensional surfaces;
- strongest potential for controlled ambient motion;
- richer visual separation between sections;
- most immediately identifiable as an AI technology studio.

## Commercial effect

The concept communicates:

- innovation;
- modern AI capability;
- system connectivity;
- visual ambition.

## Main risk

It carries the highest risk of feeling like a product startup, crypto platform, or conceptual technology brand rather than an accountable service studio. Motion and gradients would need strict limits.

# 7. PROVISIONAL RECOMMENDATION

**Concept A — Precision Grid is the strongest base direction.**

It provides the best balance of:

- recognisable ProAI continuity;
- technical authority;
- evidence-first hierarchy;
- premium restraint;
- future motion potential;
- maintainable responsive implementation.

The recommended refinement path, after owner selection, is:

- retain Concept A's dark technical system and cyan identity;
- borrow Concept B's editorial restraint, spacing discipline, and proof presentation;
- avoid Concept C's larger-radius product-dashboard feeling and continuous luminous saturation.

This is not authorization to merge concepts now. The independent review must first determine whether each candidate is internally coherent and whether Concept A is actually the strongest complete-page direction.

# 8. RESPONSIVE COMPARISON

Each concept includes a full `390 px` mobile artifact.

The mobile comparison must verify:

- full RU Hero readability;
- early primary CTA;
- no clipped status or disclosure;
- Financial Stream remains the strongest proof;
- Ways to Start remains editorial and non-pricing;
- selected-project proof classes remain understandable;
- no meaning depends on desktop-only system graphics;
- section color changes do not create excessive visual fragmentation.

The mobile concept is not a separate visual direction. It must be recognisably the same system as its desktop counterpart.

---

# 9. MOTION BOUNDARY

No motion is approved during this comparison.

A later selected-concept specification may consider:

- subtle system-line movement;
- restrained reveal sequencing;
- proof-image depth;
- hover states;
- reduced-motion equivalents.

It must reject:

- constant object spinning;
- large parallax scenes;
- cursor-dependent meaning;
- motion that delays reading or CTA access;
- effects that make the studio appear experimental rather than reliable.
