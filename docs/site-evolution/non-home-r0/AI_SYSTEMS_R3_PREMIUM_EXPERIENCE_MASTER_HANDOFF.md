## 10. Motion system

R3 needs meaningful motion at three levels.

### Ambient
Very slow, sparse, material movement:
- subtle directional sheen;
- rare registration impulse;
- depth/parallax only where useful;
- quiet light drift;
- no constant animation everywhere.

### Scroll choreography
Different sections should enter differently.
Examples:
- Hero fragments settle but remain slightly unresolved;
- Register aligns, Indigo reaches authority boundary and stops;
- engineering layers resolve in depth;
- code executes through active lines;
- agent sequence reaches Human Gate and pauses;
- Pearl chapter removes machine noise;
- Evidence freezes into immutable artifact.

### Pointer / interaction
Desktop / fine pointer only:
- controlled material response;
- line or state focus;
- code-line/trace synchronization;
- restrained metallic sheen;
- no generic `scale(1.02)` hover language.

Mobile must have separately authored touch/scroll behavior and no dependence on hover.

Every motion must explain state, execution, control or authority.
