# ProAI Cube — Semantic Brand Face R3

Base product SHA: `295a67a27df127c95d799c93ea39448afd714793`

This lab derives from the existing Semantic R2 runtime at build time. The underlying Cube geometry, slice mechanics, Presentation Motion R1.2, Materials + Lighting R1, camera system and GLB are not rewritten.

## A — Smoked Semantic Veil

One continuous, extremely thin smoked material state covers the selected assembled face. Opacity stays in the low translucent range so all nine cubies and their seams remain visible. The material uses graphite/black-chrome values, restrained clearcoat and no transmission/refraction. Pearl/Silver lettering sits microscopically above the veil with no bloom dependency.

Primary hypothesis: strongest balance between face unification and preserved Cube construction.

## B — Nine-Cubie Semantic Inlay

Nine separate rounded inlays map one-to-one to the nine visible cubie faces. The wordmark mask is UV-segmented into nine matching pieces, so typography can cross seams while the seams remain physically real. All nine pieces activate as one semantic event; there is no tile-by-tile animation.

Primary risk: excessive fragmentation. The review should reject B if the lettering reads like a tiled display rather than one distributed material inscription.

## C — Internal Optical Reveal

The outer face receives only a weak smoked material wash. Pearl/Silver lettering is built as two shallow depth layers beneath that wash: a lower, softer internal layer and a sharper upper inscription. The intent is a precision industrial optical signature under the existing surface, not a projection and not a screen.

Primary risk: becoming too subtle at mobile scale.

## Typography study

Two-line composition is selected for all three concepts:

`ProAI`

`Expert`

`ProAI` is optically dominant. A single-line lockup was not promoted because fitting both words inside the same safe face width materially reduces cap height and weakens the embedded-object reading, especially on portrait mobile.

## Shared semantic timing

The mechanical architecture remains unchanged. R3 only lengthens the semantic material state into the requested premium range: approximately 0.9s formation, 1.9s readable hold, and a slower text-first / material-second dissolution.

## Self-review rejection rules

Reject a concept if owner evidence shows any of the following:

- 3×3 structure visually disappears;
- the face reads as a monitor, plaque, tablet or billboard;
- text reads as a floating decal;
- glow becomes the main effect;
- transparency resembles generic glassmorphism;
- a hard cut is required to reveal or exit;
- a semantic layer remains rigid while a slice rotates;
- the result reads as gaming, crypto, HUD or sci-fi UI;
- `Expert` becomes an afterthought;
- modest 3/4 perspective exposes a visibly floating plane.
