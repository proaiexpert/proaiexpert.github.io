# Checklist: New Local-Service Site

- Confirm repo, branch, remote, and old HEAD.
- Confirm niche and geography.
- Collect real business facts.
- Research competitors and local search language.
- Define offer and exclusions.
- Define proof status, trust limits, risk areas, and CTA.
- Choose URL structure.
- Define EN/RU or single-language scope.
- Define homepage sections.
- Define CTA path.
- Define image strategy.
- Define deployment target.
- Create sitemap and copy strategy.
- Choose visual direction and imagery rules.
- Build homepage first, then inner pages.
- Build services, work examples/scenarios, service area, city pages, pricing, guides, about, request, and FAQ.
- Run claim-safety, desktop, tablet, mobile, link, reveal, and deployment QA.
- Save reusable lessons back into the factory docs.

Before launch, run:
- `LOCAL_SERVICE_GUARDRAILS.md`
- `QA_CHECKLIST.md`
- `MOBILE_QA.md`
- `DEPLOYMENT_QA.md`
- `CODEX_WORKFLOW.md`
