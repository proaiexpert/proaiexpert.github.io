# Checklist: New Local-Service Site

- Confirm repo, branch, remote, and old HEAD.
- Choose niche and collect business facts.
- Research competitors and local search language.
- Define offer, proof status, risk areas, and CTA.
- Create sitemap and copy strategy.
- Choose visual direction and imagery rules.
- Build homepage first, then inner pages.
- Build services, work examples/scenarios, service area, city pages, pricing, guides, about, request, and FAQ.
- Run desktop, tablet, mobile, link, content safety, reveal, and deployment QA.
- Save reusable lessons back into the factory docs.
