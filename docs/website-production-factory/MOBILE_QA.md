# Mobile QA

Required widths:
- 430px
- 390px
- 375px
- 360px
- 320px

Checks:
- header fits
- hamburger opens and closes
- sticky CTA does not cover content
- hero is readable
- cards stack without clipping
- no horizontal overflow
- footer stacks cleanly
- forms remain usable
- content is visible without JavaScript

Reveal checks:
- `.reveal` visible by default
- only `html.js .reveal` may hide content
- no `html.js.reveal`
- mobile reveal hiding disabled if reliability risk exists
- reduced-motion fallback works
