# Niche Adaptation

## Handyman
- Pages: services, work examples, service area, city pages, pricing approach, request, FAQ.
- Proof needed: real project photos, license status if claimed, service area.
- Risks: fake completed projects, warranty, insured/licensed claims.
- CTA: request estimate / send project details.

## Construction
- Proof needed: licenses, permits, insurance, real project portfolio.
- Risks: regulated claims, safety, large price claims.
- CTA: project consultation only if true; avoid "free consultation" unless verified.

## Painting
- Proof needed: before/after images, prep process, materials.
- Risks: warranty/guarantee claims.
- CTA: request painting estimate.

## Cleaning
- Proof needed: service scope, staff/background claims if used.
- Risks: insured/bonded claims, guaranteed results.
- CTA: request cleaning quote.

## Landscaping
- Proof needed: photos, seasonal services, service area.
- Risks: pesticide/licensed treatment claims.
- CTA: request yard/project estimate.

## Accounting/Bookkeeping
- Pages: services, industries, process, pricing approach, documents checklist, FAQ.
- Proof needed: credentials only if real, software expertise, compliance boundaries.
- Risks: tax/legal advice, guaranteed refunds, penalty removal.
- CTA: structured request / document review.

## Dental/Medical Clinics
- Proof needed: licensed provider facts, location, insurance/payment facts, real services.
- Risks: medical claims, outcomes, testimonials, before/after, HIPAA.
- CTA: request appointment / call clinic.

## Professional Services
- Proof needed: credentials, case studies, client permission.
- Risks: guaranteed outcomes and fake authority.
- CTA: structured inquiry.

## Adaptation Rule

Change copy, imagery, proof, CTA, and compliance notes for each niche. Do not reuse handyman assumptions blindly.
