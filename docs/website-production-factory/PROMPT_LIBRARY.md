# Prompt Library

## GitHub Setup

Verify remote, branch, HEAD, origin/main, status, and push access. Report old HEAD before changes.

## Local/GitHub Audit

Find local project files, compare to GitHub, preserve uncommitted patches, and document conflicts.

## Competitor Research

Research local competitors, service language, proof patterns, CTAs, and compliance risks. Do not copy content.

## Intake Analysis

Convert raw client notes into facts, missing facts, risks, page needs, and proof status.

## Sitemap Generation

Create homepage, services, work examples, service area, city pages, pricing, guides, about, request, FAQ.

## Copy Strategy

Write safe local-service copy. Avoid fake reviews, ratings, licenses, warranties, guarantees, and fake projects.

## Visual Direction

Define premium local visual direction, hero image, scenario imagery, color palette, typography, and CTA hierarchy.

## Homepage Concept

Build a homepage prototype with complete first screen and core sections. Verify mobile.

## Implementation

Implement scoped files only. Preserve existing patterns. Record exact files changed.

## Visual QA

Use rendered screenshots. Curl is not enough for visual bugs.

## Mobile QA

Check 430, 390, 375, 360, 320 widths. Verify hamburger, sticky CTA, reveal, card stacking, footer.

## Launch QA

Verify source HEAD, origin/main HEAD, live HTML/CSS, cache-busted URLs, noindex state.

## Live/Source Mismatch Diagnosis

Compare local source, remote source, live response headers, live content markers, and cache status.

## Deployment/Cache Diagnosis

Check Last-Modified, ETag, X-Cache. If stale CSS persists, add a unique override filename.

## Niche Adaptation

Adapt page templates, proof rules, CTA language, images, risk disclaimers, and compliance notes to the new niche.
