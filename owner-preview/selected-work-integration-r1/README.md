# Selected Work R1.6 full Homepage review adapter

Review-only Cloudflare Pages adapter for the no-build `proaiexpert-github-io` project.

- Product authority: `review/homepage-selected-work-integration-r1` production Homepage files.
- The adapter assembles the current Homepage section fragments from the same branch tree at runtime.
- Header, Technology and Footer are resolved from the current production data/template values because those Jekyll includes are parameterized.
- This directory is not production product authority and must not be used as a merge substitute.
