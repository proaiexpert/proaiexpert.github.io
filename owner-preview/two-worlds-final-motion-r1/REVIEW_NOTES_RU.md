# Two Worlds R5 R3.2 — Final Motion R1

Статус: изолированное исследование для Owner. Ничего из этой папки не является production authority.

## Что сравнивать

- D0: desktop production R3.2, контроль.
- D1: тот же desktop с синхронным движением складки, границы face clipping и 3D surface transform. Изменение только через preview CSS и только при fine pointer на ширине от 981 px.
- M0: mobile production R3.2, контроль.
- M1: тот же mobile с окончанием turn при `q=.72` вместо `.64`. Это единственное отличие preview JS. Начало AI hold, общая длина главы и момент входа Technology не меняются.

Открывайте EN/RU страницы через `index.html` в этой папке. Страницы собраны из текущего `main` и включают Header → Hero → Connected System → Two Worlds → Technology → Financial Stream. Liquid в review HTML отсутствует.

## Ключевая измеренная разница

При 393×750 пик геометрической чувствительности складки снижается с 1.63 до 1.36 px на 1 px скролла; при 852×390 — с 6.29 до 5.24. Среднее по turn: 1.27 → 1.06 и 4.87 → 4.06 соответственно. В синтетическом Chromium scroll probe максимальный видимый шаг: 4.90 → 4.00 px и 18.86 → 15.71 px. Это не замер реального iPhone.

Desktop контроль имеет фазовый разрыв: focused fold `620ms`, face clip/transform `680ms + 50ms`. В локальном кадре раннего AI→WEB приближённое расстояние от fold center до границ face — около 190–204 px у D0 против 10–22 px у D1. Геометрия вычислена по `getBoundingClientRect` и CSS clip percentages; это сравнительная оценка, не пиксельная сегментация изображения.

## Известные ограничения

- M1 не устраняет возможную асинхронность sticky stage/композитора и всё ещё оставляет высокую ландшафтную чувствительность.
- M1 сокращает WEB hold: 324 → 252 px в портрете, 183 → 142 px в ландшафте. AI hold не сокращён; Technology не сдвинута.
- В эмуляции смены ориентации с `page.setViewportSize` mid-turn прогресс прыгнул к WEB endpoint и в M0, и в M1. Это общий риск базовой реализации; результат эмуляции не заменяет проверку поворота настоящего iPhone.
- Один из локальных headless Chromium кадров на выходе из sticky stage был кратко пустым; следующий кадр восстановился. Причина не установлена.
- Внешний Google Font был недоступен в локальной песочнице, поэтому типографику и motion следует оценить на HTTPS preview.

## Рекомендация для проверки Owner

Сначала сравнить D0/D1 на desktop при нейтральном состоянии, наведении на каждый мир и прямом переходе AI↔WEB. Затем на реальном iPhone сравнить M0/M1 медленно, быстро, в обратном направлении и после поворота. M1 не считать готовым к выпуску только по эмуляции.
