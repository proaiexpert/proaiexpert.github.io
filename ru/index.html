INSIDE PROAI / LIVE SYSTEM

Реальный код. Живая система. Человек контролирует важные решения.

Один запрос превращается в структурированный контекст, подготовленное AI-решение и контролируемый следующий шаг — важные решения остаются за человеком.

Код создаёт рабочее состояние системы: запрос принимается, контекст структурируется, AI готовит данные, человек подтверждает решение, затем система переходит в состояние «Готово» с сохранённым контекстом.

const request = capture(inquiry);
const context = await enrich(request, {
  source: "website",
  intent: "new project",
});
const decision = await assist(context, {
  rules: qualifyAndRoute,
  ai: prepareBrief,
});
if (decision.requiresHuman) {
  await human.review(decision);
}
return action.resolve(decision);
